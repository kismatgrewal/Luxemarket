# Design prototypes

Self-contained HTML/CSS prototypes of LuxeMarket's key screens, built against the
same design tokens as the app (`_luxe.css` mirrors the Tailwind theme in
[`tailwind.config.ts`](../tailwind.config.ts)). They are the source for the
screenshots in the root [README](../README.md) and serve as a visual reference
for the production components.

| File | Screen |
| --- | --- |
| `home.html` | Storefront home |
| `product.html` | Product detail |
| `listing.html` | Catalog with faceted filters |
| `checkout.html` | Stripe checkout |
| `vendor.html` | Vendor dashboard |
| `admin.html` | Admin console |
| `banner.html` / `og.html` | Repository banner & social card |

Open any file directly in a browser — no build step required.
